## 同步上游 Firefly 6.15.8

本次一次性合入上游 **141 个提交**（6.13.5 → 6.15.8），并完成本地功能取舍。

### 新增

- **动态页（/dynamic/）**：以 Markdown 内容集合驱动的动态流，支持置顶、地点、图库、评论与按年过滤；**替换原「说说」页面**，旧链接 `/moments/shuoshuo/` 自动重定向
- **书签导航页（/booknav/）**：按分类整理网址收藏
- **VNDB 页（/vndb/）**：视觉小说收藏网格（当前默认关闭，可在 `siteConfig.pages` 开启）
- **Tab 代码块**：`rehype-code-group` 支持文章内多标签代码块
- **Wiki 链接**：`[[标题]]` 语法自动链接站内文章
- **图片 grid 嵌套支持**：admonition 等容器内的图片 grid 正常渲染
- **mermaid 图表交互**：拖拽平移、双指缩放（移动端）、svg 高度限制
- **樱花特效 Worker 化**：改用 Web Worker 渲染，性能更流畅
- **音乐播放器**：Meting fallback 多源容错播放、延迟初始化优化首屏、防自动播放
- **代码块体验**：复制按钮（触屏适配）、折叠渐变遮罩、行内代码用代码块主题
- **导航栏**：「我的」下拉（动态/相册/追番/VNDB/番组/书签）、毛玻璃配置、无障碍改进
- **列表与标签**：分页页码跳转、标签胶囊/矩形样式、底部标签折叠、网格封面贴边/内缩切换、封面置左
- **构建流水线**：新增资源裁剪（prune-pio / minify-inline-scripts）、Astro 升级至 7.2.0、韩语翻译

### 移除

- **Waken-wa 实时面板集成**：相关配置与组件一并移除（含 README 章节）
- **说说模块（moments/shuoshuo）**：由上游动态页替代
- **generate-icons.js / icons.ts**：图标方案改为 iconify 运行时，`pnpm icons` 命令失效

### 其他

- 修复同步脚本 `sync-upstream.sh` / `sync-upstream-full.sh` 祖先判断方向错误（此前会静默跳过同步）
- 启用 `git rerere` 记录冲突解法，后续同步自动复用
